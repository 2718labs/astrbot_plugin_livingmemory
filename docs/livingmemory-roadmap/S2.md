# S2：统一新记忆处理链

目标：让自动总结、明确记忆和后续 rebuild 都消费 S1 的同一高标准产物契约，并从同一 parent/fact 真源建立可供 S5 使用的事实级索引。

非目标：不迁移、清洗或兼容实例旧记忆；不处理默认关闭的 consolidation；不比较、聚合、重写或取代历史记忆；不在本阶段重建图谱或调整召回分数。

## S2-01：唯一处理链

- 所有入口最终调用同一套校验、规范化、幂等去重和持久化逻辑。
- 入口只负责表达来源意图，不能各自重新解释 fact、topic 和关系。
- 同一规范输入从不同入口进入，除来源字段外应得到相同 canonical 结果。
- 写文档成功但下游对象失败时，必须有清楚的未完成状态，不把半成品标成 active。
- 这里的去重只防止同一来源窗口或确定相同输入重复写入，不包含跨历史记忆的语义聚合。
- pipeline 明确区分 S0 三种结果：`store` 才进入构建；`skip` 零写入并正常完成；`invalid` 零写入并保留待重试来源。

## S2-02：统一入口语义

- 自动总结：遵守 S0 价值判断和 S1 结构。
- 明确记忆工具：保留用户主动保存意图，但仍走字段校验、来源记录和去重。
- import/restore 的旧格式兼容不在当前范围；新格式 rebuild 只重放 canonical 数据。

## S2-03：parent 与 canonical fact 持久化

- parent memory 只保存稳定来源窗口、scope、生成版本、幂等键和必要的一句中性概览。
- processor 输出的 `key_facts` 对象在校验后规范化为独立 fact 记录；每条记录拥有稳定 fact ID、parent ID、直接来源和 S1 规定的对象字段。
- parent 不再复制保存整组事实正文，只保留 fact IDs 或可重建关系；对外需要 LM 风格 JSON 时，从 canonical fact 记录重组 `key_facts`。
- canonical fact 记录是唯一权威事实数据；document text、字符串 fact 列表、API 外壳和索引文本都只能由它重建。
- 为尚未切换的内部消费者提供统一投影函数，不在数据库中长期并存对象版与字符串版两套 facts。
- parent 写入成功但任一 required fact 或来源关系失败时，本次构建不得进入 active 完成态。

## S2-04：事实级搜索投影

- FTS 和向量索引按 fact 建立，索引键必须能直接回到 fact ID 和 parent ID。
- 索引正文只使用 fact 本身及必要的主体、规范时间和可复用 topic；不拼接长 summary、其他 sibling facts 或 persona reaction。
- reaction 作为命中 fact 的可选返回载荷保存，不参加搜索向量和关键词正文。
- S5 切换前可以保留 document route 作为改造前生产基准，但它只能是同一 canonical 数据的临时投影，不得形成第二套写入语义。
- rebuild 从 canonical facts 重放索引；不得反向从 document content 或旧 Atom 猜回事实。

## S2-05：下游只接收 canonical 产物

- 文档、FTS、向量、Atom 候选和图输入都只能由通过 S1 校验的 canonical 产物生成。
- 失败或拒写结果不能留下部分下游对象。
- 不为 legacy 文档补造新字段，也不让它们参与新链路验收。

## S2-06：干净重建与验收

- 使用干净 fixture 数据库从零运行新写入链并重建 parent store、fact store、事实级 FTS 和向量索引。
- 核对 parent 数、fact 数、scope、persona、来源键、fact-parent 映射和事实向量数量。
- 实例数据库和旧索引不进入重建输入，也不要求生成映射。
- 图谱和 Atom 分别等 S3、S4 再接入。
- 自动总结、明确记忆和 rebuild 对同一规范输入产出相同 canonical 字段。
- 干净库不存在拒写残留、部分下游对象或重复 active。
- 同一 fact 从不同入口写入时，除来源意图字段外得到同一规范内容和索引文本。
- 用 S0 基线同时记录临时 document route 与 fact candidate route；本阶段不切换最终注入，也不和实例旧库做迁移对账。

## 完成条件

### 实现记录（2026-08-21）

- 新增 `memory_parents` 与 `memory_facts`：parent 只保存稳定来源、scope、生成版本、幂等键、中性概览和 fact IDs；完整 fact 对象只保存于 `memory_facts.fact_json`。
- 自动总结、`/lmem summarize`、主动记忆工具和直接 v3 写入统一进入 `add_canonical_memory()`；主动记忆由程序构造同一 v3 fact 契约，不再生成 v2 字符串 facts。
- 父文档只作为 S5 前的临时 document-route 投影；读取详情时再从 canonical fact 记录重组 LM 风格 `key_facts`，数据库不并存第二份 facts 真源。
- 新增独立的 fact FTS 与 `livingmemory_facts.index` 向量库；索引正文只由 fact、直接参与者、规范时间和 fact 自身 topic 组成，不包含 sibling facts、长 summary 或 persona reaction。
- `/lmem rebuild-index` 同时检查和重建事实索引；`rebuild_canonical_indexes()` 只从 active canonical facts 重放 FTS 与向量投影，并提供不接入生产召回的双路候选查询用于 S0/S5 对照。
- canonical 写入先保持父文档不可召回，fact 与两种索引全部成功后才激活；真实 SQLite/FAISS 故障测试确认向量写入失败时 document、parent、fact 与 fact FTS 均为零残留。
- 新 canonical 写入暂不生成图或 Atom；它们分别等 S3、S4 依据 canonical facts 接回。未读取、迁移、清洗或补造实例旧记忆。
