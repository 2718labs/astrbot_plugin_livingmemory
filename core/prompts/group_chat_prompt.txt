# 任务
从下面的群聊窗口中提取值得长期保存的事实。窗口只是来源范围，不等于一条记忆；按可独立复用的中心拆成零条、一条或多条记忆。

当前日期时间：{current_date}

# 消息格式
- `[M1]`、`[M2]` 是本窗口内的稳定引用编号，只能在 `source_indexes` 中使用这些编号。
- `[昵称 | ID: 账号 | 时间]` 是群成员消息；`[Bot: 昵称 | ID: 账号 | 时间]` 是你的消息。
- 事实必须写具体昵称和完整主体，不能用“用户”“群成员”“有人”“她”“他”“那个”“后来”等脱离来源就无法理解的指代。
- 平台的 Error、Warning 等系统标识不是对话事实。

# 判断和拆分
- 先把同一件事在窗口里的前后说法串起来，再提取事实。后面的明确否认、纠正、澄清或群体最终决定，覆盖前面的误解、试探和临时说法；只保存窗口结束时成立的状态。
- 如果某个说法后来被纠正，不得把旧说法当作另一条事实保存；`source_indexes` 应指向最终说法及其直接依据。
- 自动总结只提取本窗口中新确认的信息。Bot 自己复述的旧记忆、对成员过去行为的单方面声称、人格设定和自我介绍，不得再次写成新记忆；只有相关成员在本窗口直接确认或补充后，才能作为成员事实。
- 每条候选事实独立选择 `store` 或 `skip`。
- `store`：窗口结束后仍可能复用的身份、偏好、关系、明确计划、群体决定、重要事件、反复问题，或明确要求记住的内容。
- `skip`：寒暄、灌水、一次性玩笑、临时报错过程、即时状态、重复无新增内容。
- 判断 `store` 前先问：把这条 fact 单独放到几周或几个月后的另一场对话里，它是否仍能帮助理解某个成员、成员关系、群体决定或尚未完成的事情？只能还原本轮包袱、斗嘴过程或短暂心情的内容用 `skip`。
- 同一个玩笑在本窗口里重复很多次，仍是一次性玩笑，不算“反复问题”；出现次数多、篇幅长或语气强烈，都不能代替长期价值。
- 单次喊昵称、使用亲昵称呼或做出某个动作，只是本轮行为，不自动等于稳定偏好；必须有明确表达、跨窗口一致证据或群体约定，才可用 `store`。
- 成员明确表达不喜欢某种互动方式、提出边界或偏好，并得到接受或形成约定时，应保存最终偏好和约定；不要保存此前被否认的比喻或解释。
- 默认用 `skip`。只有能明确归入稳定身份或偏好、关系边界或约定、待办计划、持续问题、重要事件、明确要求记住之一时才用 `store`；“真实发生过”本身不等于值得长期保存。
- 一条 memory 只围绕一个中心；彼此无关的事实放进不同 memory。
- 每条 fact 只表达一件事，并保留必要主体、时间、条件和状态。
- topic 是可跨记忆复用的概念，如“团建”“驾考”“插件开发”，不是一次性聊天标题。
- topics 和 participants 必须属于当前 fact，不得把整段群聊的所有标签或发言者复制给每条 fact。
- `source_indexes` 只指向能够直接支撑当前 fact 的消息编号。
- `time` 只表示 fact 正文中明确提到的事件时间。`time.raw` 必须逐字摘自所引用消息的正文，不能复制消息头里的发送日期或时间；消息头时间只用于换算“昨晚”“周三”等相对时间表达。正文没有时间表达时必须写 null。
- `persona_reaction` 只记录你当时很短的情绪和想法；不复述 fact、不冒充群成员事实，没有价值时写 null。
- summary 只写一句中性概览；程序会从获准 facts 重新派生它。

# 输出
只输出合法 JSON：

```json
{
  "memories": [
    {
      "summary": "张三组织周五的团队聚餐",
      "topics": ["团队聚餐"],
      "key_facts": [
        {
          "fact": "张三组织本周五的团队聚餐",
          "action": "store",
          "topics": ["团队聚餐"],
          "participants": ["张三"],
          "time": {"raw": "本周五", "normalized": "2026-08-21", "precision": "day"},
          "importance": 0.75,
          "source": "user_explicit",
          "source_indexes": [1],
          "persona_reaction": null
        }
      ],
      "sentiment": "positive",
      "importance": 0.75
    }
  ]
}
```

约束：
- 顶层只能有 `memories`；最多 5 条 memory，每条最多 5 个 key_facts。
- `source` 只能是 `user_explicit`、`assistant_explicit`、`assistant_observed`、`group_consensus`、`inferred`。
- `time.precision` 只能是 `day`、`minute`、`month`、`year`。
- `sentiment` 只能是 `positive`、`neutral`、`negative`；importance 必须在 0.0 到 1.0。
- 不要为了让数组非空而编造事实；没有候选时输出 `{"memories":[]}`。
